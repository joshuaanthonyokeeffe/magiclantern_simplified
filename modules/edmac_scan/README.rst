edmac_scan
==========

DIGIC 6 EDMAC Channel Scanner.

Scans all 47 EDMAC DMA channels during LiveView to identify the sensor readout
channel (RAW_LV_EDMAC_CHANNEL_ADDR) and confirm the EDMAC MMIO base address.
Run during LiveView; output saved to ML/LOGS/EDMAC_SCAN.LOG.

:Summary: DIGIC 6 EDMAC channel scanner for ROM analysis
